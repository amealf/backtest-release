# 项目目标

## 长期目标

修复成交真实性，并让 V4.3 使用仓库本地运行输入实现可复现。

## 当前里程碑

保留按冻结四视图契约完成终局闭合的五轮 max-W 证据；不建立 Round 6，也不接受任何参数。任何外部验证都需要新的用户授权契约。

## 成功标准

| 标准 | 衡量方式 | 状态 |
| --- | --- | --- |
| 成交真实性 | 信号驱动平仓不能在无真实成交的 bar 上成交。 | 当前 |
| 开仓连续性 | pending entry 保留已确认的「第一根真实成交 bar open」行为。 | 当前 |
| 可复现性 | 活跃运行依赖从仓库相对路径与哈希绑定输入解析。 | 当前 |
| 可审计性 | 新的 V4.3 身份与 pending-exit 证据可将结果和 V4.2 区分。 | 当前 |

## 非目标

- 不修改 V4.2 源码或结果。
- 缺少用户明确指令、已冻结 V4.3 计划、精确反连接或通过的 validate-only 门禁时，不运行参数探索。
- 不从实现测试宣称参数已被接受。

## 维护规则

只有用户改变长期目标、优先级或已确认成功标准时更新本文件。临时工作写入 `03_active_work\CURRENT_TASKS.en.md`。
