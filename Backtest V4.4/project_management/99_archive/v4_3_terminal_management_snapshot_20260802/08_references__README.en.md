## Adding a reference

- Use a stable ID and real path or URL.
- Record origin, date, owner when known, intended use, and review status.
- State whether the source is current authority, supporting context, historical evidence, or an unverified lead.
- Store large retained files outside this index and link them.

## Maintenance

Update when a source is added, replaced, rechecked, loses relevance, or changes provenance.
