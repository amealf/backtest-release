# 存档说明

## 用途

保留非活动材料以便追溯，同时避免它与当前事实混淆。存档改变状态，不抹除历史。

## 规则

- 每个存档项目使用带日期或稳定描述的目录。
- 存档说明包含原用途、生效区间、退役原因、存在时的替代项与保留证据路径。
- 存档材料不能出现在当前权威表与当前任务结论中。
- 复用项目前阅读对应存档说明。
- 只有记录决策并更新有效边界后，才能恢复材料。
- 日常项目上下文维护不得永久删除文件。

## 维护规则

存档结构或保留规则变化、材料转为非活动或项目恢复时更新。
