# Archive Guide

## Purpose

Retain inactive material for traceability without confusing it with current truth. Archiving changes status; it does not erase history.

## Rules

- Give each archived item a dated or stable descriptive folder.
- Add an archive note with the original purpose, active period, retirement reason, replacement when one exists, and paths to retained evidence.
- Keep archived material out of current authority tables and active task claims.
- Read an item's archive note before reusing it.
- Restore material only through a recorded decision and an updated validity boundary.
- Do not permanently delete files as part of routine project-context maintenance.
