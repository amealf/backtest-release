# 后续研究方向

当前累计证据共有 1,775 个坐标、449,850 笔交易和五个兼容阶段。Continuation 第二轮把情景一与全坐标成本后总收益的领先组合都推到 E320／BH240／TRW12／K1.25／W6／M4.5 附近，两者主要差在速度窗口 S340 与 S400。以下内容是可以检验的研究问题，不包含回测执行或 HTML 交付规则。

## 1. 判断领先点是否位于稳定参数区域

围绕共同的 E320／BH240／TRW12／K1.25／W6／M4.5 结构，检查 W、M 与 S 的邻近组合。重点观察 S340 到 S400 之间是否存在连续平台或参数脊线，而不只比较两个最高点。情景一与全坐标目标继续分别解释。

## 2. 做时间分段与样本外检验

把当前领先组合冻结为候选，在与现有训练期不重叠的数据上验证收益、最大回撤、交易数和排名是否仍然稳定。也可以在现有样本内按时间分段，检查结果是否集中在少数日期或单一市场阶段。

## 3. 量化跨 gap 交易依赖

当前情景一与全坐标领先组合排除跨 gap 交易后的毛收益分别为 -0.3590% 与 +0.1949%。后续研究需要拆分跨 gap 与非跨 gap 的收益贡献、交易次数和回撤，判断当前优势是否主要来自隔夜或缺口行情。排除 gap 收益在现行方法中仍只作诊断；若要改变排名规则，需要另立研究范围。

## 4. 检查成本与交易频率稳健性

使用哈希绑定的 K200M 当前名义价值成本参考，对合理的滑点和手续费情景做敏感度分析。观察领先组合在成本变化后是否仍保持正收益和相近排名，并比较高频组合与当前 113／130 笔候选的可实现性。原始成交和原始收益保持不变。

## 5. 扩展跨品种迁移证据

首个冻结候选迁移已经在 SImain SIH6 的 2026-01-29 至 2026-02-23 区间完成。后续可以增加不重叠的 SImain 区间、其他品种，或单独标注的 SImain 全网格事后诊断。每项扩展都必须在目标评价前冻结候选，并使用目标合约的乘数、最小变动单位、交易时段、手续费及数据质量假设。

## 6. 比较其他定义方法

把当前的净下跌、反弹确认与 W 基准定义作为对照组，另行检验替代定义能否提高时间稳定性、降低 gap 依赖或减少参数敏感度。替代定义属于新的方法身份，其结果需要和现行 V4.4 证据分开解释。
